# Implementation Milestones

1. [[Milestone 1 - RPG Foundation]] — persistent character/profession progression, XP tracks, dimension-gate foundation, profiles, resources, Affix Pages, stat calculation.
2. [[Milestone 2 - Character Gameplay]] — class combat, skill allocation/ranks, keybind limit, prerequisites, exclusions, combat respec.
3. [[Milestone 3 - Itemization and Crafting]] — Affix Pages, itemization, Crafting profession, affix manipulation/salvaging foundation.
4. [[Milestone 4 - World Progression]] — world/dimension gates, configurable dimension integration, encounter progression.
5. [[Milestone 5 - Class Depth and Content]] — expanded skills and the initial playable Mining, Logging, Farming, and Crafting profession content.
6. [[Milestone 6 - Endgame]] — challenge progression, advanced mastery, gear goals, events, and replayability within the level caps.

The progression architecture and all four initial profession tracks belong to the vertical-slice plan. The milestones describe implementation sequencing, not a requirement to fully populate every future ability tree before the slice can be tested.
