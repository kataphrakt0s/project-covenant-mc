# Implementation Priorities

Immediate priority: [[Milestone 1 - RPG Foundation]]. Prove that a character can level, equip an existing Minecraft item with an Affix Page, gain its modifiers, unequip without losing the page, transfer it to another player, and retain it after save/reload.

Architectural priorities: define [[Stat Calculation Pipeline]] early; keep profile and item data separate; make core independent of integrations; develop against clean current NeoForge before ATM11.

Defer world generation, large class roster, extensive talents, and endgame content until foundations are stable.
