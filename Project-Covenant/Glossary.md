# Glossary

- **Affix:** Item modifier changing RPG properties.
- **Affix Page:** Item-bound RPG data attached to an individual Minecraft stack.
- **Character profile:** Persistent player-owned RPG progression data.
- **Derived statistic:** Calculated stat based on base attributes and modifier sources.
- **Specialization:** Focused class path that changes playstyle.
- **Stat aggregation:** Combining applicable modifiers into effective stats.
