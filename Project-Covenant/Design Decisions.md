# Design Decisions

| Area | Decision |
|---|---|
| World | Comprehensive RPG overhaul |
| Classes | Traditional identities plus within-class customization |
| Loot | Crafting-oriented; retain special direct drops |
| Combat | Hybrid Minecraft combat and RPG systems |
| Endgame | Escalating challenges, dungeons/bosses, open-world progression |
| Level cap | 100 |
| Attributes | Strength, Dexterity, Constitution, Intelligence, Willpower, Ego |
| Example classes | Warrior/Rage, Mage/Mana, Hunter/Focus |
| Equipment | Existing vanilla/modded items participate |
| Affix Pages | Per-item-stack data that travels with item |
| Compatibility | Standalone; ATM11 target, not dependency |
| Development | Clean NeoForge dev environment, then ATM11 |
