# Statistics

The implemented foundation has six direct stats: Health, Damage, Armor, Movement Speed, Attack Speed, and Dodge. It also defines neutral skill multipliers for Resource Cost, Cooldown, Cast Time, and Skill Duration, without implementing skills or resources.

Use Minecraft attributes and native equipment modifiers. Permanent character state remains separate from ItemStack-owned Affix Pages and effective equipment values. Primary attributes, points, talents, and conditional modifier frameworks are outside this stage.

See [the implementation contract](../docs/RPG_STATS.md) for stat IDs, units, defaults, and limits.
