# Equipment

Existing vanilla and modded equipment should participate in RPG itemization without losing its original identity. RPG data attaches to item instances through [[Affix Pages]].

Modifiers apply only while equipped. Unequipping preserves data. Categories must be extensible; class identity should not unnecessarily restrict gear.
