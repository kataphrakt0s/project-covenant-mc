# Attributes

## Current decision

The traditional primary-attribute model (Strength, Dexterity, Constitution, Intelligence, Willpower, and Ego) is **not part of the current Project Covenant design**. Characters do not receive attribute points at level-up, and there is no primary-attribute allocation screen or attribute-point economy.

Character levels primarily fund the class skill tree. General numerical character development comes from equipment and [[Affix Pages]], skill effects, and modest profession bonuses where deliberately designed.

## Direct statistics

The current stat vocabulary is Health, Damage, Armor, Movement Speed, Attack Speed, and Dodge. Skill tuning also uses Resource Cost, Cooldown, Cast Time, and Skill Duration modifiers.

See [[Statistics]], [[Stat Calculation Pipeline]], [[Character Progression]], and [[Combat Skill Progression]].

This file is retained as a Vault landing page for existing links. It does not define an active primary-attribute system.
