# Character Progression

Established: level cap 100; configurable XP curve; persistent, server-authoritative progression; development through attributes, class, specialization, talents, abilities, and gear.

Planned skill progression: skills have multiple ranks purchased from a skill-point
pool that gains one point per character level. XP progression, the point economy,
and rank scaling are deferred while the roster and dependencies are designed in
[[Skill Trees Brainstorm]]. Current free prototype learning is unchanged.

To design: XP pacing/sources, attribute and talent point schedules, respec rules, post-100 progression.
