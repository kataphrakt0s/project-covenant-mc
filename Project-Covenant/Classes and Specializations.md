# Classes and Specializations

Hybrid model: recognizable class identities with meaningful within-class customization. Classes define identity, abilities, and primary resource. Specializations change playstyle; talents create build-defining choices. Classes do not rigidly restrict equipment.

Examples: Warrior ([[Class Resources#Rage|Rage]]), Mage ([[Class Resources#Mana|Mana]]), Hunter ([[Class Resources#Focus|Focus]]). Not a final roster.
