# Mod Compatibility

Covenant is standalone; ATM11 is a target compatibility test environment, not a dependency.

Support vanilla/modded equipment and entities, optional adapters, and extension points. Avoid unnecessarily replacing vanilla damage/combat. Keep core independent of integrations.

Develop on a clean current-version NeoForge instance, then validate against ATM11 on Minecraft 26.1.2.
