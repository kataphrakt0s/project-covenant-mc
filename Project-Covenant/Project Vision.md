# Project Vision

Covenant delivers a deep, Minecraft-native RPG progression experience—not merely a stat overlay and not an ARPG transplanted into a 3D world. It builds on the activities, systems, dimensions, equipment, and modding ecosystem that make Minecraft compelling.

**Guiding principle:** Minecraft mods should contribute to the RPG rather than be replaced by it.

Covenant should reward combat, exploration, mining, logging, farming, crafting, and other meaningful participation. It must preserve baseline vanilla functionality and keep vanilla XP independent from Covenant progression.
