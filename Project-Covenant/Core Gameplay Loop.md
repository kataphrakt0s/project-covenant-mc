# Core Gameplay Loop

Explore → encounter → earn XP/materials/rewards → develop character/build → craft and customize → tackle harder content → repeat.

Short term: encounters and gathering. Medium term: levels, abilities, crafting, gear. Long term: build completion, region mastery, dungeons, bosses, endgame.
