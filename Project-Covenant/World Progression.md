# World Progression

Comprehensive RPG progression while preserving Minecraft's exploration freedom. Regions and dimensions have distinct identities, danger ranges, enemies, resources, equipment opportunities, dungeons, and bosses. Difficulty reflects region, encounter role, and world context—not indiscriminate player-level scaling of every entity.

## Dimensional progression gates

XP progression is gated by configurable maximum levels for each progression track in each dimension. Character progression and each profession (Mining, Logging, Farming, Crafting) can have different caps in the same dimension. Rules match exact dimension identifiers or dimension tags, with configured priority and a fallback. The default unmatched-dimension caps are character 60 and profession 20.

A gate controls where a progression track can earn more XP; it does not prevent physical access to a dimension or reduce a level already earned. XP earned past a dimension's gate is discarded, not banked. See [[Dimensional Progression Gates]].
