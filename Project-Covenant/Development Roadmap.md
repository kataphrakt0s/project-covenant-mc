# Development Roadmap

1. [[Milestone 1 - RPG Foundation]] — profile, character/profession XP tracks, level caps, dimension-gate foundation, resources, item data, and stats.
2. [[Milestone 2 - Character Gameplay]] — class combat and rank-based skill progression.
3. [[Milestone 3 - Itemization and Crafting]] — gear customization, salvaging, and initial Crafting-profession content.
4. [[Milestone 4 - World Progression]] — dimensions, world progression, and configurable gates.
5. [[Milestone 5 - Class Depth and Content]] — initial playable profession trees/recipes for all four professions and expanded class abilities.
6. [[Milestone 6 - Endgame]] — challenge tiers, advanced mastery, gear goals, and long-term content.

See [[Progression Vertical Slice]] for the integrated scope and acceptance criteria.
